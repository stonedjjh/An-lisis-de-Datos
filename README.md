# Análisis de Datos

Este repositorio centraliza mi proceso de aprendizaje y documentación sobre Análisis de Datos. Aquí iré creando entradas y registros de los diferentes temas, ejercicios y proyectos prácticos que vaya estudiando.

## Índice de Contenidos

- [Gestión de Datos](./Gestion%20de%20Datos)
- [Ejercicios Prácticos](./Ejercicios_Practicos)
- [Recursos y Utilidades](./Recursos)

## Objetivos del Repositorio

- Documentar conceptos técnicos relacionados con el análisis de datos.
- Mantener un registro de los scripts y ejercicios prácticos resueltos.
- Crear una base de conocimiento personal (hojas de trucos, referencias, etc.) para consultar a lo largo del proceso de estudio.

## Estructura

A medida que avance en los temas, se irán agregando carpetas y archivos específicos para cada área de estudio o módulo de aprendizaje.

## Requisitos Previos

Para ejecutar los ejemplos de código que se irán añadiendo, se recomienda tener instalado Python junto con las bibliotecas estándar de análisis de datos:

``bash
pip install pandas numpy
``
