# 1. Análisis Exploratorio de Datos (EDA)

El **Análisis Exploratorio de Datos (EDA - Exploratory Data Analysis)** es un enfoque fundamental en la ciencia de datos. Consiste en analizar la información antes de aplicar algoritmos complejos, con el objetivo de:

- Resumir las características principales de los datos.
- Obtener una mejor comprensión del conjunto de datos (dataset).
- Descubrir relaciones ocultas entre diferentes variables.
- Extraer las variables más importantes para resolver el problema.

**Pregunta principal de este módulo:** En nuestro caso práctico de los autos, la pregunta central del EDA es: *¿Cuáles son las características (variables) que tienen el mayor impacto en el precio del automóvil?*

## Técnicas de EDA a estudiar
Para responder a esa pregunta, en este módulo exploraremos las siguientes técnicas:

1.  **Estadísticas Descriptivas:** Describen las características básicas del dataset y proporcionan un resumen conciso de las medidas.
2.  **Agrupación de Datos (GroupBy):** Conceptos básicos para agrupar datos y transformar nuestro dataset.
3.  **ANOVA (Análisis de Varianza):** Un método estadístico que divide la variación de un conjunto de observaciones en componentes distintos para ver qué tan diferentes son.
4.  **Correlación:** Métodos para encontrar la relación estadística entre diferentes variables (incluyendo Correlación de Pearson y Mapas de Calor o *Heatmaps*).
